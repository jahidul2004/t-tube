# T-Tube

**T-Tube** is a demo platform similar to YouTube, where users can explore, watch, videos thumbnail and details. It offers a user-friendly interface and essential video browsing features.

## Website

Visit the live website: [T-Tube](https://jahidul2004.github.io/t-tube)

---

## Features

- **Search Functionality**: Quickly find videos by keywords.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices.
- **Clean User Interface**: Easy navigation and a pleasant viewing experience.

---

## Technologies Used

- **Frontend**: HTML, CSS(Tailwind), JavaScript
- **Hosting**: GitHub Pages

---

## How to Use

1. Open the [T-Tube](https://jahidul2004.github.io/t-tube) website.
2. Browse through the video library or use the search bar to find specific videos.
3. Click on a video to watch it.
4. Enjoy seamless video playback!

---

Note:This project is mainly focused for begainers who want to explore API.
